# EDRdog Frontend 기능 명세

지금 구현된 것 기준이다. 데이터는 전부 백엔드 `api-service` 에서 온다.

## F1. 랜딩과 로그인

| | |
|---|---|
| `/` | 서비스 소개. 히어로, 기능 소개, 공격 경로 쇼케이스, CTA, 테마 토글 |
| `/login` | 로그인과 회원가입 통합 폼(탭 전환) |
| 세션 | 토큰을 localStorage 에 두고 새로고침해도 유지한다. 값이 깨져 있으면 로그아웃 상태로 시작 |

## F2. 비로그인 데모

조회 탭은 **로그인 없이 열린다.** 토큰이 없으면 데모 데이터를 그린다. 처음 온 사람이 서비스가 무엇을 보여주는지 볼 수 있어야 해서다.

`/me/*` 와 `/tenant/*`(개인 설정)는 데모가 없다. 보여줄 "예시" 가 없는 영역이라 비로그인 시 호출하지 않는다.

## F3. 대시보드 (`/dashboard`)

미판단 위협 수와 주간 탐지 수 타일, 공격 경로 재구성, 최근 탐지 위협 목록, 엔드포인트 상태 도넛, 위협 유형 TOP5, 위협 탐지 추이 차트, 이벤트 유형별 건수.

## F4. 조사 화면

| 경로 | 보여주는 것 |
|---|---|
| `/threats` | 알림 목록. 심각도·상태 칩 필터, 호스트·도메인·목적지IP 필터, 페이지네이션 |
| `/endpoints` | 호스트 목록. 정상/주의/위험/**수집없음** 필터 |
| `/endpoints/:host` | 호스트 상세. 요약, 프로세스 트리, 이 호스트의 위협·사건·최근 로그 |
| `/events` | 원시 이벤트. 기간·호스트·유형 필터, 행 펼침으로 상세 필드와 원본 JSON |
| `/incidents` | 사건 목록(알림을 프로세스 계보로 묶은 것). 기간·상태 필터 |
| `/incidents/:id` | 사건 상세. 요약, 사건 단위 트리아지, 계보, 구성 알림, 증거 사슬, 전개 타임라인 |

"수집없음" 을 "정상" 과 분리한 이유는 등록만 되고 이벤트가 없는 기기에 초록을 쓰면 검증 안 된 상태를 좋다고 말하는 셈이기 때문이다. 중립색으로 따로 둔다.

## F5. 분석 화면

| 경로 | 보여주는 것 |
|---|---|
| `/intelligence` | 관계 분석. 엔드포인트 → 목적지 egress 토폴로지 그래프. 알림 유무로 선 스타일 구분 |
| `/lookup` | IP·도메인 조회. 상관 그래프(관측/추정/실시간DNS 출처 구분) + 실시간 정·역방향 DNS |
| `/map` | 위협 지도. 외부 연결 목적지를 국가별로 집계해 세계지도에 표시 |

**관측·추정·실시간 조회를 시각적으로 구분한다.** 셋을 같게 보여주면 추측이 관측으로 읽힌다.

## F6. 대응

알림이나 사건에서 확인을 거쳐 프로세스 종료를 지시한다. `POST /api/alerts/:id/respond` 로 api-service 를 거쳐 나간다. 결과는 1초 간격 폴링으로 받고 40초가 상한이다.

격리(isolate)는 백엔드에 구현이 없어 프로세스 종료로 대신한다. 화면에 격리로 남겨 두면 격리된 줄 알고 넘어가게 되므로 표현을 걷어냈다.

## F7. 온보딩 (`/onboarding`)

에이전트 설치 안내(OS별 명령과 경로), Slack webhook 등록, 기기 상태 확인, 내 기기 등록.

설치 링크는 서버가 준 것을 그대로 쓴다. 화면에서 조립하지 않는다. 둘이 어긋나면 사용자가 붙여넣은 명령이 조용히 틀린 곳을 가리킨다.

enroll secret 은 화면에 보여주지 않는다. 키를 사람 손에 쥐여 주면 채팅방에 붙고 스크린샷에 남는다.

## F8. 공통 기능

| | |
|---|---|
| 통합 검색 | 상단바. 서버 `GET /api/search` 를 친다 |
| 자동 새로고침 | 10/30/60/300초. **기본값은 꺼짐** |
| 테마 | 다크/라이트 토글. 최초값은 OS 설정 추종 |
| 반응형 | 모바일 드로어 |

## 비기능 요건

| | |
|---|---|
| 번들 | Vercel Hobby 플랜 안에서 돌아야 한다. echarts 를 쓰는 화면은 지연 로드한다 |
| 아이콘 | 외부 아이콘 라이브러리와 이모지를 쓰지 않는다. 인라인 SVG 만 |
| 색 | 심각도 전용. 이벤트 유형 같은 다른 축에 색을 주지 않는다 |
| 지어내지 않기 | 로그인 상태의 빈 화면을 예시 데이터로 채우지 않는다 |
| 서버 규칙 | 서버가 정하는 판정 규칙을 화면 문구에 옮겨 적지 않는다 |
| 필터·검색 | 화면에서 거르지 않고 서버에 넘긴다 |
