# 008. 모바일 브라우저에서 드로어 하단이 가려졌다

## 증상
모바일에서 사이드바 드로어를 열면 아래쪽 메뉴가 잘려 보이지 않았다.

## 원인
드로어 높이가 `h-screen`(100vh)이었다. 모바일 브라우저에서 `100vh` 는 **주소창을 포함한 높이**라 실제 보이는 영역보다 크다.

## 해결
`h-dvh` 로 바꿔 보이는 영역에 맞춘다.

## 재발 방지
모바일에서 전체 높이를 쓰는 자리는 `vh` 가 아니라 `dvh` 를 쓴다. 데스크톱 브라우저에서는 둘이 같아서 차이가 드러나지 않는다.
