# 012. 배포 직후 열려 있던 탭에서 위협 지도(/map)가 뜨지 않았다

## 증상
운영(2026-11-11)에서 데모로 /map 에 들어가면 화면이 안 떴다가, 잠시 뒤 다시 하니 떴다. 배포 직후에만 생긴다.

## 원인
화면별 코드는 따로 나뉜 파일(`/assets/ThreatMap-해시.js`)로 필요할 때 받는다. 배포하면 해시가 바뀌어 옛 파일은 사라진다. 배포 전에 열어 둔 탭은 옛 이름을 부른다.

여기에 `vercel.json` 이 모든 주소를 `index.html` 로 돌려서, 없는 js 파일을 불러도 404 가 아니라 200 HTML 이 왔다. 브라우저는 HTML 을 스크립트로 읽다 실패하고 화면이 멈춘다. 새로고침하면 새 이름을 받아서 다시 됐다.

## 해결
- `src/main.tsx`: Vite 가 화면 파일을 못 받으면 내는 `vite:preloadError` 에서 한 번 새로고침한다. 10초 안에 또 실패하면 다시 하지 않는다(진짜 장애에서 무한 새로고침 방지).
- `vercel.json`: `/assets/` 는 `index.html` 로 돌리지 않는다. 없는 파일은 404 로 빨리 실패한다.

## 재발 방지
**SPA 되돌리기 규칙은 정적 파일 경로(`/assets/`)를 빼고 건다.** 화면을 나눠 받는 코드는 배포 뒤 옛 탭에서 깨질 수 있다는 것을 전제로 한다.
