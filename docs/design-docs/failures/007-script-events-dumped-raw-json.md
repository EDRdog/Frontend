# 007. script 이벤트를 모르는 유형이라 원본 JSON 을 그대로 뿌렸다

## 증상
이벤트 목록 요약 칸에 `detail` 원본 JSON 이 그대로 나왔다. 유형 필터에서 고를 수도 없었다.

## 원인
인터프리터 실행은 `process` 가 아니라 `script` 로 분류돼 온다. 화면이 그 유형을 모르니 처리 분기가 없어 원본을 뿌렸다.

**7일간 189,688건으로 전체의 22%** 인 유형이었다.

## 해결
`script` 를 `process` 와 같은 규칙으로 보여준다. 필터에도 넣었다.

## 재발 방지
백엔드가 이벤트 유형을 늘리면 화면도 같이 늘어나야 한다. 모르는 유형이 들어왔을 때 원본을 그대로 뿌리는 것은 **조용한 실패가 아니라 시끄러운 실패**라 그나마 발견됐다.

새 유형을 추가할 때는 Backend 의 `event-schema` 의 `EventTypes` 와 이 화면의 분기를 같이 본다.
