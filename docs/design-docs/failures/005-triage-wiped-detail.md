# 005. 사건 트리아지 한 번에 계보와 구성 알림이 사라졌다

## 증상
사건 상세에서 확정/오탐 판단을 내리는 순간, 프로세스 계보와 구성 알림이 "받지 못했습니다" 로 바뀌었다.

## 원인
트리아지 응답은 **목록 형태**라 `alerts` 와 `lineage` 가 `null` 이다. 그 응답으로 상세를 통째로 갈아치우고 있었다.

## 해결
트리아지 응답으로는 바뀐 필드만 반영하고 상세를 덮어쓰지 않는다.

## 재발 방지
같은 엔티티라도 **응답마다 채워지는 필드가 다르다.** 목록 응답을 상세에 그대로 대입하면 상세에만 있던 것이 지워진다.

부분 응답을 상태에 넣을 때는 머지인지 교체인지 먼저 정한다.
