# 002. 실데이터에서 관계 그래프 높이가 18000px 로 늘어났다

## 증상
관계 분석 그래프 높이가 18120px, 문서 전체가 19939px 로 늘어나 훑을 수가 없었다.

## 원인
열 배치가 **균형 잡힌 그래프를 가정**하고 있었다. 실제 응답은 엔드포인트 1개가 목적지 200곳으로 뻗는 별 모양이다. 한 열에 200개가 세로로 쌓였다.

**데모에서는 안 걸렸다.** 노드가 10개뿐이라 그 가정이 깨지지 않았다.

## 해결
한 열이 8개를 넘으면 접는다. 서버 기본 관계 수도 200에서 50으로 줄였다.

## 재발 방지
레이아웃 코드는 데이터 모양을 가정한다. 그 가정을 데모 데이터로만 확인하면 실데이터에서 깨진다. 데모는 노드가 10개고 실데이터는 별 모양이었다.

새 시각화를 붙일 때는 **가장 치우친 모양**(한 노드가 전부와 연결된 경우)을 먼저 넣어 본다.
