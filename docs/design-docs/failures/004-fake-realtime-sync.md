# 004. 상단바가 실시간 동기화 중이라면서 아무것도 갱신하지 않았다

## 증상
상단바에 "실시간 동기화 중" 이 떠 있었다. 실제로는 화면을 열 때 한 번 받고 끝이었다. 폴링도 스트림도 없었다.

## 원인
표시만 있고 구현이 없었다. 화면에 적힌 문구가 동작과 어긋나 있었다.

## 해결
`refresh` 스토어를 만들어 실제로 갱신을 돌리고, 간격을 사용자가 고르게 했다. 기본값은 꺼짐이다.

## 재발 방지
**동작을 설명하는 UI 문구는 그 동작이 있을 때만 쓴다.** 이 레포에서 같은 유형이 반복됐다.

- "폴링 방식이라 반영까지 수십 초" — Fleet 이 kill 을 대신하던 때의 설명이 에이전트 전환 후에도 남아 있었다
- 호스트 상태 판정 규칙을 화면에 적었는데 서버가 규칙을 바꾸기로 했다
- Slack 채널이 이미 붙었는데 스크립트가 "아직 없다" 고 찍고 있었다 (Backend)

문구가 사실인지는 코드가 아니라 **동작**으로 확인한다.
