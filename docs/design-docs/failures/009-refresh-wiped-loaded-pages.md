# 009. 새로고침이 쌓아 둔 쪽을 지웠다

## 증상
목록을 여러 쪽 내려본 뒤 자동 새로고침이 돌면 첫 쪽만 남고 나머지가 사라졌다.

## 원인
재조회가 첫 쪽만 받아 상태를 교체했다. 사용자가 쌓아 둔 쪽을 고려하지 않았다.

같은 100줄짜리 목록 훅이 **세 곳에 복사**돼 있었다. 미묘한 비동기 로직이 세 벌이면 같은 결함도 세 번 고쳐야 한다.

## 해결
조건이 그대로인 재조회면 지금까지 쌓인 만큼을 한 번에 되받는다. 훅은 `usePagedList` 하나로 모았다.

## 재발 방지
**복사된 비동기 로직은 결함도 같이 복사한다.** 같은 훅이 두 번째로 복사되려 하면 그때 공용으로 뺀다.

재조회 때 화면을 비우지 않는 규칙도 같이 넣었다. 자동 새로고침마다 비우면 보던 줄이 사라진다.
