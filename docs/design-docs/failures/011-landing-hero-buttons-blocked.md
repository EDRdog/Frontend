# 011. 랜딩 첫 화면의 데모 보기·로그인 버튼이 눌리지 않았다

## 증상
운영 랜딩(2026-11-11 확인) 첫 화면에서 데모 보기, 로그인 버튼을 눌러도 아무 일도 일어나지 않았다. 데스크톱과 휴대폰(iPhone 13 에뮬레이션) 둘 다 같았다. 사용자는 모바일에서 스크롤이 안 먹힌다고 느꼈다. 스크롤 자체는 됐고, 누르는 것이 안 됐다.

## 원인
히어로는 세 장면(이벤트 흐름 → 탐지 → 대시보드)을 한 무대(`.hx-stage`)에 겹쳐 두고 투명도로 바꾼다. 2·3장 요소(`.hx-dash` z-index 3, `.hx-count`, `.hx-head`, `.hx-gtag`)는 1장 동안 `opacity: 0` 으로 숨어 있을 뿐 자리는 그대로라, 1장 버튼 위에 깔려 터치와 클릭을 가로챘다. 투명한 요소도 이벤트를 받는다.

화면으로는 보이지 않아서 스크린샷 검사로는 잡히지 않았다. Playwright 로 버튼을 누르려 할 때 `<div class="hx-dash"> intercepts pointer events` 가 나와서 알았다.

## 해결
보여주기용 요소(`.hx-dash, .hx-chip, .hx-count, .hx-gtag, .hx-head`)에 `pointer-events: none` 을 줬다. 대시보드는 그림일 뿐 누를 곳이 없다.

## 재발 방지
**장면을 겹쳐 두고 투명도로 바꾸는 연출에는 숨은 장면에 `pointer-events: none` 을 같이 준다.**

랜딩을 고치면 버튼과 링크가 실제로 눌리는지 본다. 각 요소를 화면 가운데로 스크롤한 뒤 `document.elementFromPoint` 로 그 자리의 맨 위 요소가 자기 자신인지 확인하면 된다. 이번에는 이 방법으로 휴대폰, 데스크톱 각각 24개를 확인했다.
