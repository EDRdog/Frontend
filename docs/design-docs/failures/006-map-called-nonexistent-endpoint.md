# 006. 로그인하면 지도가 비었다. 없는 경로를 부르고 있었다

## 증상
비로그인 데모에서는 지도가 잘 나오는데, 로그인하면 비었다.

## 원인
프론트가 `GET /alerts/geo` 를 부르는데 백엔드에는 그 경로가 없다. 실제 경로는 `GET /events/geo` 다.

**데모가 버그를 가렸다.** 비로그인 상태에서는 `demoApi` 가 응답하므로 잘못된 경로가 드러나지 않았다.

## 해결
백엔드의 `events/geo` 응답 형태에 맞췄다.

## 재발 방지
데모 폴백이 있는 화면은 **로그인 상태로도 확인해야 한다.** 데모만 보면 API 경로가 틀려도 화면이 정상으로 보인다.

같은 성격의 사건이 하나 더 있다. 그래프 레이아웃 결함도 데모 노드 10개에서는 안 걸리고 실데이터에서만 터졌다(`002-*`).
