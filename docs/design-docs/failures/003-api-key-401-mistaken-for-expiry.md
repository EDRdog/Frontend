# 003. API key 401 을 토큰 만료로 오인해 조용히 로그아웃시켰다

## 증상
온보딩에서 설정을 저장하려 하면 아무 설명 없이 로그아웃됐다. 다시 로그인해도 같은 일이 반복됐다.

## 원인
`client.ts` 가 401 을 전부 토큰 만료로 보고 `useAuthStore.clear()` 를 불렀다.

그런데 `/tenant/` 경로는 `X-API-Key` 를 강제한다. 그 키가 틀려서 나온 401 은 **재로그인해도 해결되지 않는다.** 사용자는 원인을 모른 채 같은 일을 반복하게 된다.

## 해결
`/tenant/` 경로의 401 은 `clear()` 하지 않고 원인을 화면에 남긴다.

## 재발 방지
같은 상태 코드라도 원인이 다르면 대응이 달라야 한다. "401 = 재로그인" 은 토큰이 유일한 인증 수단일 때만 맞다.

이 수정은 "온보딩에서 등록이 조용히 실패하던 지점들" 5건 묶음의 하나다. 나머지도 전부 **실패가 조용했던** 것이 공통점이다.
