수집 알림 연동

기기당 1회 설치·등록을 마치면 이벤트 수집과 실제 조치가 동작합니다. 조치(kill)는 같은 에이전트가 실행하고 결과를 보고할 때까지 서버가 기다렸다가 응답합니다.

로그인하면 여기서 바로 발급·저장·등록할 수 있습니다.로그인

1. 기기 설치 및 로그 수집

설치 링크를 발급해 나온 한 줄을 대상 기기에서 실행하세요. 프로세스·파일·네트워크를 한 에이전트가 모두 수집합니다.

로그인하면 내 조직의 설치 링크를 발급할 수 있습니다.
  1. 터미널에서 명령 실행

    위에서 발급한 한 줄을 터미널에 붙여넣습니다. 중간에 권한 승인을 기다리므로 터미널에서 직접 실행해야 합니다.

  2. 전체 디스크 접근(FDA) 승인

    이 단계만 사람이 직접 해야 합니다. 스크립트가 설정 창을 열어 주면 아래 경로를 추가한 뒤 켜고 Enter를 누르세요.

    /usr/local/bin/edrdog-agent
  3. 결과 확인

    등록 완료가 보이면 끝난 것입니다. ERR_NOT_PERMITTED가 보이면 권한을 껐다 다시 켠 뒤 재시작하고 로그를 확인하세요.

    sudo launchctl kickstart -k system/com.edrdog.agent
tail -n 50 /var/log/edrdog/agent.log

2. Slack 알림 연결

Slack Incoming Webhook을 발급받아 등록하면 탐지 알림이 이 채널로 전달됩니다.

webhook만 등록하면 알림은 오지 않습니다. 아래 4번 내 기기 등록까지 마쳐야 그 기기의 알림이 이 채널로 전달됩니다.
  1. api.slack.com/apps 접속 → Create New App → From scratch 선택
  2. 앱 이름 입력, 알림을 받을 워크스페이스 선택 후 생성
  3. 좌측 메뉴 Incoming Webhooks → Activate Incoming Webhooks 켜기
  4. Add New Webhook to Workspace → 알림 받을 채널 선택 → Allow
  5. 생성된 Webhook URL(https://hooks.slack.com/services/...) 복사 후 아래 입력칸에 붙여넣기
https://hooks.slack.com/services/...
