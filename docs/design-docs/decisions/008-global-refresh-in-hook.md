# 008. 전역 새로고침을 훅 안에서 구독하고 기본값은 끈다

- 날짜: 2026-08-01
- 상태: 채택

## 배경
상단바가 "실시간 동기화 중" 이라고 표시하면서 실제로는 아무것도 갱신하지 않고 있었다. 폴링도 스트림도 없이 화면을 열 때 한 번 받고 끝이었다.

## 결정
- `refresh` 스토어(version, lastAt, interval)를 두고 **`useApi`·`usePagedList` 안에서 구독한다.** 각 화면이 알아서 구독하게 두지 않는다.
- 자동 새로고침 **기본값은 꺼짐**이다. 간격은 10/30/60/300초 중에 사용자가 고른다.
- 재조회 때 화면을 비우지 않는다. 같은 조건이면 이전 값을 두고 조용히 바꾼다. 목록은 지금까지 쌓인 쪽만큼을 한 번에 되받는다.

## 근거
**훅 안에서 구독하는 이유**:
> 각 화면이 알아서 구독하게 두지 않고 useApi 안에서 한 번에 받는다. 페이지마다 deps 에 넣게 하면 빠뜨린 화면만 멈춘 데이터를 보여주는데, 그건 새로 받는 것보다 나쁘다.

**기본값이 꺼짐인 이유**:
> 켜 두면 조사하는 도중에 목록이 바뀌어 보던 줄을 놓친다. 켜는 것은 사용자가 정한다.

**재조회 때 비우지 않는 이유**:
> 자동 새로고침마다 화면을 비우면 보던 줄이 사라진다. / 첫 쪽만 받으면 페이지를 내려보던 사용자의 목록이 갱신 때마다 사라진다.

## 결과/영향
- 훅을 거치지 않고 `api/` 를 직접 부르면 그 화면만 갱신에서 빠진다. `ARCHITECTURE.md` 의 의존 방향에 적었다.
- StrictMode 의 이중 렌더 때문에 렌더 중에 판정하면 두 번째가 같은 조건으로 잘못 읽힌다. 훅 안에서 그걸 피한다.
