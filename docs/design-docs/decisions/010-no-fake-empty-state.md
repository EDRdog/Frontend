# 010. 로그인 상태에서 빈 화면을 예시 데이터로 채우지 않는다

- 날짜: 2026-07-26
- 상태: 채택

## 배경
지도가 비어 보이는 것이 허전해서 예시 집계를 깔아 뒀다.

## 결정
로그인 상태에서는 폴백과 "예시 데이터" 표기를 걷어내고 빈 상태로 둔다. 대신 빈 상태를 안내 문구로 만든다. 비로그인 데모에서는 예시로 채운다.

없는 값을 지어내지 않는 규칙은 지도뿐 아니라 전역이다.

| 자리 | 하는 일 |
|---|---|
| 지도 | 비어 있으면 "아직 수집된 외부 연결이 없습니다" |
| 사건 목록 | 원본 이벤트를 못 찾으면 프로세스명을 지어내지 않고 빈 문자열 |
| IP·도메인 조회 | 토폴로지에 있는 것만 그린다 |

## 근거
> 비어 있어도 예시 집계로 채우지 않는다. 남의 나라 탐지 건수를 보여주면 자기 조직 데이터로 오해한다.

이 화면은 조사 결과를 보여주는 자리다. 지어낸 값이 섞이면 사용자가 그걸 믿고 엉뚱한 결론을 낸다.

같은 이유로 **관측·추정·실시간 조회를 시각적으로 구분한다.** 셋을 같게 보여주면 추측이 관측으로 읽힌다.

## 결과/영향
- 비로그인 데모와 로그인 상태의 빈 화면 동작이 다르다. 데모는 보여줄 것이 목적이라 채우고, 로그인 상태는 사실이 목적이라 비운다.
- "수집 없음" 을 "정상" 과 다른 색으로 둔다. 등록만 되고 이벤트가 없는 기기에 초록을 쓰면 검증 안 된 상태를 좋다고 말하는 셈이다.
