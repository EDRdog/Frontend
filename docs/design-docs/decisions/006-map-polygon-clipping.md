# 006. 지도 폴리곤을 직접 자르고 중심 경도를 150°E 로 둔다

- 날짜: 2026-07-25
- 상태: 채택

## 배경
`world-atlas` 110m 을 echarts geo 에 그대로 등록하니 지도가 깨져 보였다.

## 결정
등록 전에 링을 펴서(unwrap) 이음매에서 Sutherland-Hodgman 으로 자르고 제자리로 되돌린다(normalize). 중심 경도는 150°E.

## 근거
> world-atlas 110m 은 러시아·피지·남극처럼 날짜변경선을 넘는 나라를 폴리곤 하나에 담아 두는데, 링 안에서 경도가 179°→-179° 로 건너뛴다. echarts geo 는 경위도를 평면에 그대로 찍으므로 그 한 변이 지도를 가로지르는 띠가 된다.

**중심 경도 150°E 를 고른 이유**:
> 중심을 정확히 127°E(서울)로 두면 이음매가 53°W 라 브라질이 좌우로 잘리므로 150°E 로 잡았다. 이음매가 대서양 30°W 에 떨어져 아메리카·아프리카가 온전하다(그린란드만 나뉜다).

**외부 의존성을 늘리지 않았다.** 투영 라이브러리를 들이는 대신 필요한 클리핑만 직접 구현했다.

## 결과/영향
- 그린란드는 나뉜 채로 둔다. 어느 중심을 고르든 한 곳은 잘리고, 그린란드가 가장 덜 아프다.
- 클리핑 코드를 직접 들고 있어야 한다. world-atlas 를 갈아끼우면 다시 봐야 한다.
- 확대한 뒤 다른 지역을 보려면 이동이 필요한데 `roam` 이 `'scale'` 이라 좌클릭 드래그가 막혀 있다. 휠클릭 드래그 팬을 따로 붙였다.
