# 011. 서버가 정하는 규칙을 화면 문구에 옮겨 적지 않는다

- 날짜: 2026-08-01
- 상태: 채택

## 배경
호스트 상태가 어떻게 정해지는지 화면에 설명으로 적었다. 적은 직후에 백엔드가 `status` 를 `riskScore` 의 함수로 바꾸기로 했다.

## 결정
서버가 정하는 판정 규칙은 화면 문구에 적지 않는다. 적은 것을 도로 뺐다.

## 근거
> 방금 넣은 문구가 곧 거짓이 된다. 서버 규칙을 화면 문구에 옮겨 적으면 규칙이 바뀔 때 화면만 옛 설명을 사실처럼 계속 보여준다.

틀린 설명은 없는 설명보다 나쁘다. 사용자는 화면에 적힌 것을 믿는다.

## 결과/영향
- 상태나 위험도가 어떻게 계산되는지 궁금하면 백엔드 문서를 봐야 한다.
- 같은 원칙이 설치 안내에도 적용된다. 설치 링크를 화면에서 조립하지 않고 서버가 준 것을 그대로 쓴다. 둘이 어긋나면 사용자가 붙여넣은 명령이 조용히 틀린 곳을 가리킨다.
