# 005. 관계 그래프를 echarts 대신 SVG 로 직접 그린다

- 날짜: 2026-07-31
- 상태: 채택

## 배경
관계 분석과 IP·도메인 조회 화면에 그래프가 필요했다. 처음에는 echarts 의 `graph` 시리즈를 썼다.

## 결정
echarts `graph` 를 버리고 SVG 로 직접 그린다. 힘 배치(force layout)도 쓰지 않고 열 기반으로 세운다. `RelationGraph.tsx` 하나를 두 화면이 공유한다.

## 근거
> echarts graph 시리즈는 노드가 점이고 라벨이 그 아래 흩어져 완성도가 떨어졌다. SVG 로 직접 그려 카드 노드·연결점·베지어 곡선·라벨 박스·점 격자를 만든다. 힘 배치도 걷어냈다. 컨테이너 밖으로 퍼져도 되돌리지 않아 노드가 잘렸다.

열 배치의 추가 이득:
> 열로 세우면 잘림도 없고 무엇이 무엇으로 나갔는지도 그대로 읽힌다.

## 결과/영향
- 레이아웃을 직접 관리해야 한다. 실데이터에서 한 열이 200개로 뻗어 높이가 18000px 이 된 적이 있다(`docs/design-docs/failures/002-*`).
- 긴 프로세스 이름이 옆 칸과 겹치던 문제는 캔버스로 실제 텍스트 폭을 재서 해결했다.
- 그래프에 관해서는 echarts 의존이 없다. echarts 는 추이 차트와 지도에만 쓴다.
