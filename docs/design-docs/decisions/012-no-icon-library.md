# 012. 아이콘 라이브러리를 쓰지 않는다

- 날짜: 2026-07-31
- 상태: 채택

## 배경
대시보드에 아이콘이 필요한 자리가 여럿이다(프로세스·네트워크·파일 구분, 사이드바 진입점, OS 표시).

## 결정
외부 아이콘 라이브러리와 이모지를 쓰지 않는다. 필요한 것은 인라인 SVG 로 직접 둔다(`src/components/ui/icons.tsx`). 로고도 직접 가공한 에셋이다.

## 근거
히스토리 전체에서 `lucide`, `react-icons`, `heroicons` 류가 `package.json` 에 추가되거나 제거된 적이 한 번도 없다. 처음부터 들이지 않았다.

실제 적용 사례:
> 백엔드는 platform 을 OS 아이콘용으로 안내했지만 이 프로젝트는 아이콘을 쓰지 않아 글자로 표시한다.

아이콘 세트 하나가 번들에 들어가면 쓰는 아이콘이 서넛이어도 값을 치른다. Vercel Hobby 플랜 안에서 돌려야 하는 제약과 맞지 않는다.

## 결과/영향
- 새 아이콘이 필요하면 SVG 를 직접 넣어야 한다. 의도한 마찰이다.
- 파비콘은 크기별로 따로 넣는다. 탭 아이콘은 실제로 16~32px 로 그려지는데 큰 이미지 하나만 주면 브라우저가 줄이면서 뭉갠다.
