# 002. 조회 탭은 로그인 없이 열고, 토큰이 없으면 데모 데이터를 그린다

- 날짜: 2026-07-24
- 상태: 채택

## 배경
처음에는 `RequireAuth` 라우트 가드로 전부 막았다. 모든 조회 API 가 세션 Bearer 를 요구했기 때문이다. 그런데 그러면 처음 온 사람이 서비스가 무엇을 보여주는지 전혀 볼 수 없다.

## 결정
보호 라우트를 쓰지 않는다. 데이터 조회 탭은 로그인 없이 열리고, 토큰이 없으면 `src/api/demo.ts` 의 데모 데이터를 그린다. 판정은 `api/index.ts` 의 `isDemo()`(토큰이 `null` 인지)가 한다.

`/me/*` 와 `/tenant/*` 는 데모 폴백을 두지 않는다. 비로그인 시 아예 호출하지 않는다.

## 근거
두 단계로 갔다. 먼저 `/dashboard` 만 데모로 열고(`c412416`), 이어서 나머지 조회 탭도 `RequireAuth` 밖으로 옮겼다(`ca24ae1`).

개인 설정은 보여줄 "예시" 가 없다. 남의 webhook 주소를 지어내 보여줄 수는 없으니 그쪽만 닫아 둔다.

## 결과/영향
- **`src/components/RequireAuth.tsx` 가 죽은 코드로 남았다.** 어디서도 import 되지 않는다. 지우지 않아서 다음 사람이 살아 있는 가드로 읽을 수 있다(`docs/exec-plans/tech-debt.md`).
- 데모와 실데이터의 차이가 버그를 가린 적이 있다. 지도가 없는 경로를 부르고 있었는데 데모에서는 `demoApi` 가 응답해서 드러나지 않았다(`docs/design-docs/failures/006-*`).
- 데모 상태와 로그인 상태의 빈 화면 정책이 다르다. 로그인 상태에서는 예시로 채우지 않는다([010](010-no-fake-empty-state.md)).
