# 009. 검색과 필터를 서버에서 한다

- 날짜: 2026-08-01
- 상태: 채택

## 배경
상단바 검색이 받아 둔 알림 1000건 안에서만 부분일치시키고 있었다. 목록 필터도 화면에서 걸렀다.

## 결정
검색은 `GET /api/search` 로 옮긴다. 목록 필터(유형, 호스트, 기간 등)도 서버에 넘긴다.

## 근거
> 호스트가 7대뿐일 때는 티가 안 났지만 이벤트가 76만 건이라 화면이 훑을 수 있는 범위가 실제 데이터의 극히 일부였고, 그걸 '검색 결과'라고 보여주고 있었다.

필터도 같은 문제다.
> 유형은 서버에 넘겨서 거른다. 화면에서 거르면 받아 둔 쪽 안에서만 걸러져 실제와 다른 목록이 된다.

**틀린 결과를 빠르게 주는 것보다 맞는 결과를 주는 것이 낫다.** 이 화면은 보안 조사에 쓰인다.

## 결과/영향
- 검색어마다 요청이 나간다. 디바운스로 완화한다.
- 서버가 지원하지 않는 축으로는 필터할 수 없다. 화면에서 임의로 거르지 않는다.
