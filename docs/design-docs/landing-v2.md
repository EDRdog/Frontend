# 랜딩 v2 설계

- 날짜: 2026-11-11
- 상태: 구현됨 (#103, `src/components/landing/`). 시안은 `previews/landing-v2.html`
- 토큰: `DESIGN.md` 미드나잇 그대로

## 흐름
한 페이지가 제품이 하는 일을 순서대로 보여준다. 스크롤할 때마다 다음 단계로 넘어간다.

| 순서 | 섹션 | 연출 |
|---|---|---|
| 1 | 히어로 `#hero` (고정 320%) | 이벤트가 쏟아진다 → 가운데 탐지선(탐지 규칙 312개)을 지나며 위협 5개만 잡힌다 → 빈 대시보드에 잡힌 위협이 날아가 KPI, 경보 표, 심각도 막대를 채운다. 문장: 수많은 이벤트 속에서 / 위협만 골라내고 / 한 화면에 정리합니다 |
| 2 | 조사·대응 `#flow` (고정 280%) | 채워진 대시보드에서 web-03 경보를 연다 → 증거 체인, 프로세스 트리 → 프로세스 종료, 종료 완료, 격리 |
| 3 | 위협 지도·관계 분석 `#map` | 점 세계 지도에서 해외 연결이 서울로 들어오는 궤적 + 외부 연결 목록, 사건 하나의 흔적을 잇는 관계 그래프 |
| 4 | 기능·CTA `#features` `#start` | 기능 6개 벤토(타일마다 작은 실제 동작), 큰 마무리 문장, 푸터 |

## 왜 이렇게 정했나
- 1차 히어로 시안 5개(확장 카드, 단어 회전, 증거 체인, 수렴, 제품 시연, `previews/landing-hero.html`)는 모두 버렸다. 사용자 평가: 서비스와 안 맞고 밋밋하다.
- 사용자 제안: 이벤트 → 탐지 → 빈 대시보드 채우기를 스크롤 단계로. 제품이 실제로 하는 일과 화면이 그대로 이어져 채택.
- 3D 지구 히어로, 강아지 로고 입자 연출은 진행 중에 방향이 바뀌어 버렸다.
- raea(Render Anything Engine)로 영상 히어로를 만드는 안은 버렸다. 영상 용량이 Vercel Hobby 대역폭에 부담이고 스크롤과 맞물리기 어렵다.

## 구현 메모
- GSAP + ScrollTrigger, canvas 는 화면 밖에서 멈춘다. `prefers-reduced-motion` 이면 마지막 상태만 보여준다.
- 예외: 관계 그래프의 선은 SVG `stroke-dashoffset` 으로 그린다(DESIGN.md 6장은 transform, opacity 만 허용). 채택해 DESIGN.md 6장에 예외로 적었다(`docs/design-docs/decisions/014-landing-scroll-storytelling.md`).
- 세계 지도 점 데이터는 Natural Earth(공개)에서 뽑아 HTML 에 넣었다. 외부 요청 없음.
- 섹션 조각은 따로 만들어 `_base.html` 에 합쳤다. React 로 옮길 때 섹션 하나가 컴포넌트 하나다.
